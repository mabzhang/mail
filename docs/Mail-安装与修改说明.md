# Mail 1.0.0 安装与修改说明

已通过历史聊天与本机交付文件确认：你提到的 v15 是本次检索到的最新独立邮件助手，内部版本为 1.0.0-zenx.beta.15。现已按开发手册与当前 Hana 官方 v2 工具改造为 Mail 1.0.0。

## 安装

1. 使用 Hana 1.5.48-beta 或更新版本。
2. 在扩展市场的「已安装」页选择从 ZIP 安装，导入 `app-mail-1.0.0.zip`。
3. 审阅并批准 Mail 使用的模型与受管邮件后台权限，从应用入口打开。
4. 在设置填写自己的邮箱、IMAP/SMTP 主机和第三方客户端授权码；选择你在 Hana 中配置的模型。

新安装不会带入任何现成邮箱、授权码、个人署名、公司域、模型或快捷短语。自动总结和外部天气均默认关闭。邮箱授权码仅在本次后台运行的内存中；后台重新加载/退出后，需编辑原账号重新填写授权码。

Mail 使用独立 id `mail`，不会覆盖或自动搬迁旧邮件助手。旧缓存/草稿/联系人如需迁移，应另行制定迁移范围，不能把个人资料塞进对外安装包。

- 修复模型超时/截断/取消挂起、总结失败重复自动触发、SMTP 适配器与发送缓存恢复问题。
- 保留邮件阅读、排版/CID 图片、AI 总结/写作、签名提取、草稿/附件、人工确认发送、联系人和工作日历。
- 增加空值、内存凭据、SDK、受管后台与模型流等回归；合计 207 项通过。

## 包装与上传状态

`app-mail-1.0.0.zip` 是官方打包器生成的安装包，`app-mail-1.0.0.entry.json` 是其市场元数据与 SHA-256 回执。entry 的 publisher 使用产品名 Mail；它不是已确认的开发者账号认证。正式提交时应按实际作者信息、公开仓库和正式 Release 地址完成市场材料。

官方市场还要求公开仓库、正式 Release、安装 ZIP 和 entry，并通过 registry/approval PR 审核；不能把本地 ZIP 生成视为已上架。参照 [官方投稿说明](https://github.com/liliMozi/hana-marketplace/blob/main/CONTRIBUTING.md)。本次没有创建仓库、公开上传、提交 PR 或安装到你的实际 Hana。

配套 `Mail-源码与验证.zip` 不是安装包；其中包含完整可运行源码、测试、审查表、指纹、最终校验回执和界面截图。第三方库与现有 AGPL-3.0 许可均保留。

真实邮箱/模型、Windows/Linux 原生运行与真实 Hana 安装尚未验证。官方隔离启动成功不能代替这些测试。
