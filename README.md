# Mail · Hana 内嵌多邮箱工作台

**App ID：`mail` · 版本 1.0.1 · 需要 Hana 1.5.48-beta 或更新版本**

Mail 把多邮箱阅读、邮件回顾、AI 润色与回复、联系人、草稿和工作日历放进同一个 Hana 工作台。新装即白纸：不预填邮箱、主机、模型、署名或快捷短语。

## 核心能力

- 多 IMAP 邮箱统一阅读、搜索与筛选；只读操作不改变邮件已读状态。
- 当日总结与任意区间回顾；用 Hana 中选定的模型润色、起草回复、学习个人写作风格。
- 本地联系人、CSV 导入、分组、签名、附件与草稿；发送前预览并人工确认，状态不确定不自动重发。
- 邮件整理会议与跟进事项，本地工作日历，ICS 导入导出。
- 授权码只在后台本次运行内存中，不落盘；模型密钥不保存、不直连。

## 安装

在 Hana 扩展市场的「已安装」页导入 `app-mail-1.0.1.zip`，核对并批准权限；安装包已含运行依赖。之后在设置填写邮箱、IMAP/SMTP 主机端口与授权码，并在 Hana 模型目录选定模型。

## 权限与外部服务

`app/tools.expose-to-model`（三个只读 Agent 工具）、`app/runtime.execute`、`app/runtime.native`、`app/runtime.network`（native IMAP/SMTP 及可选天气）、`app/models.infer`（总结/润色/回复，可能产生费用）。天气默认关闭（`www.nmc.cn` / `api.met.no` / `myip.ipip.net`）。邮件外部图片默认阻止。
